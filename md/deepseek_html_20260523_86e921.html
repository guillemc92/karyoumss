¿Qué es un Skill?

Un Skill es un perfil experto que instruye a la IA para que adopte tu arquitectura, respete tu FSD, use tu stack y mantenga trazabilidad. No improvisa: ejecuta.

📁 karyoumss/.claude/skills/karyoumss-cytogenetic-analysis/SKILL.md
SIN Skill
La IA alucina, inventa dependencias, ignora tu BRD/FSD.
Usuario → IA genérica → código frágil (sin reglas)
CON Skill
La IA obedece tu dominio, escribe tests, documenta trazabilidad.
Usuario → Skill → Agent → código especializado + tests + ADR
🤖 agentes IA

Agent + Skill = flujo profesional

Agent es la IA que trabaja dentro del repositorio (Claude Code, Cursor).
El Skill actúa como su “manual de estilo técnico”.

> Usa el skill karyoumss-cytogenetic-analysis e implementa FSD-UC-004

El agent lee el Skill, aplica reglas de trazabilidad y genera código alineado con FSD + ADR.

🧩 Cadena: Usuario → Skill → Agent → Código + tests + traza
Cursor no lee Skills nativos → .cursor/rules/*.mdc (equivalente funcional). Claude Code sí acepta skills en .claude/skills/.
